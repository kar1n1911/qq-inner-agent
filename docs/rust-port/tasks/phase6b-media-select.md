# P6b 装饰素材的选择与发送

你是 qq-inner-agent 的工程师。**前置:P5b 必须已合并**(素材已能采集、去重、索引)。

## 定位:新功能,**只做 Rust**

后端已确定转向 Rust:新设计**只做 Rust,不再补 JS 实现**。

但本阶段与前几阶段不同 —— 它会**改动已迁移模块的既有行为**(选择逻辑、学习信号),
所以有一条硬要求:

> **改动既有行为的部分必须做成可开关且默认关闭**,默认路径与 JS 逐字一致
> (既有 parity 测试照旧全过),生产里打开开关才启用新行为。

理由:`config`/`store`/`memory`/`policy` 这些模块有 JS↔Rust 交叉验证,
那是本项目唯一能证明"Rust 没跑偏"的东西。新行为若默认开启,对照会直接失败。

**全新功能**(`groupActivity`、群作息学习、交流阶段分类、注意力漂移的参数)
在 JS 里本来就没有对应物,**不受此限**:直接 Rust 实现 + 行为测试。

## 必读

`docs/prompt-and-learning-design.md` 的 **九、十、十一、十二、十三节**。本阶段实现的是第十~十三节与第九节的 ②③ 层。

## 任务

### 1. `groupActivity`(第十节)

**它与自身的活跃节奏是两回事**,必须单独实现:

- 该群**人类**消息的衰减速率(近 5 / 30 分钟加权);
- 以及**距上一条人类消息多久**;
- **不要**复用自己的 `activity` 节奏充当它。

### 2. 该群自己的作息(第十一节 11.6 第 3 条)

从**历史消息的时段分布**学出"这个群通常什么时候安静",用于**扣除时段因素**。
绝不能套用全局 `quiet` —— 深夜的沉默不是冷场。

### 3. 目标相关度随活跃度移动(第十节 10.2)

| 群状态 | 目标相关度 | 允许的语气 |
| --- | --- | --- |
| 活跃 | **高** | 可给观点/论点;可**组合多个高频群特征** |
| 冷清 | **低** | **必须温和**,不带观点 |

相关度用**已有分词/相似度**算(粗粒度即可),**不要额外调模型**。

### 4. 按场合分桶的适配度(第十二节)

- 打分主体是 **(素材 × 场合)** 而不是素材本身;
- **`mildness` = 该素材在"冷清期救场"这一桶里的适配度**,是**学出来的**;
- **温度是硬门槛**:该桶适配度不足 → **直接丢弃**,不进入概率抽签。

### 5. 触发:概率 + 先排除后触发(第十节 10.3、第十二节 12.2)

> 可以开新话题 = 群静默超阈值 **且** 上一话题处于「收束」或「自然终止」**且** 不是"刚有人说了话还没人回"

**必须先排除**:不在该群作息内;刚有人发言无人应答(那是回应问题,不该盖过去);
有人在等回应(与 `expectations` 冲突时**优先回应**)。

通过后才用 `p_active` / `p_quiet` 抽签;**冷清期概率随静默时长上升、到顶封住**;主动冷却与每小时配额照旧。

### 6. 学习信号:先分类,再评价(第十一节 11.4)

**这是本阶段最容易做错的地方**:

- **只有** `话题处于「收束」或「自然终止」` **且** `与上文是「接续」或「转向」` 时,
  "之后是否有人继续"才是有效信号;
- **其他组合里的沉默一律剔除**,不得记为负面;
- 分类器返回 `confident: false` → **只记录、不学习**;
- **不能只奖励"有人回复"** —— 否则会学会制造争议换活跃度;负面互动同样要计入;
- 学习**严格按群隔离**。

### 7. 选择与发送

- 用**当前情境 vs 素材累积情景**做相似度检索(复用 `media_contexts`);
- **检索不到足够匹配的素材时:不发**(宁可沉默);
- **⚠️ 三条红线**(第十三节 13.5,必须写进代码与测试):
  1. **上下文只作索引,绝不进输出**;
  2. **不做人身指向**("谁用过这张图"只能当弱信号);
  3. **不用来翻旧账**。
- 频率按该群人类的表情使用率学习,**冷启动保守**。

## 硬性约束

1. 不得引入新依赖。
2. **不得改动 `rust/` 以外的文件**以外的既有契约;提示词如需改动,单独提交并说明。
3. 中文注释,重点标注:信号剔除规则、温度硬门槛、三条红线、以及"不确定就不学"。

## 验收标准

1. 两边构建/clippy/测试全过(JS 允许既有的 macOS 平台失败)。
2. 测试覆盖:
   - **沉默被剔除**:话题收束后的沉默、单发消息后的沉默,**都不得产生负面信号**;
   - `confident: false` 时不产生任何学习;
   - 温度不足的素材**不会被选中**(即使概率抽中);
   - 检索无匹配 → **不发**;
   - `groupActivity` 与自身 activity 节奏**独立**(构造"我活跃但群冷清"的用例);
   - 作息扣除:该群深夜时段**不触发**开新话题;
   - 学习**按群隔离**(A 群学到的不会影响 B 群)。
3. 不访问真实网络、不写真实 `data/`。

## 交付

1. 提交在 `rust/` 内(`cargo test` 全过),并说明新行为的开关名与默认值。
2. 用一段话回报:实现了什么、测试怎么跑、**信号剔除规则怎么验证的**、与设计的偏差或不确定点。

## 📌 补充:**注意力漂移**取代二值化的"高/低相关度"

`docs/prompt-and-learning-design.md` **第 10.4 节**(与 MaiBot 的 `attention_drift` 同构)。
前面第 3 节写的"目标相关度高/低"是**意图**,实现要用这三个参数:

| 参数 | 作用 | 取值 |
| --- | --- | --- |
| `drift_level` | 允许偏离当前话题多远 | `subtle` / `active` / `scattered` / `wild` |
| `anchor_policy` | 跑偏之后多强地回钩当前上下文 | `strict` / `balanced` / `loose` |
| `reaction_style` | 短反应的风格 | `reserved` / `natural` / `lively` |

**映射**:

- **活跃** → `drift_level` 低(subtle / active)+ `anchor_policy` 偏 `strict` —— 接得住当前话题;
- **冷清** → `drift_level` 高(scattered)+ `anchor_policy` 偏 `loose` —— 允许跳到外围;
- `reaction_style` 随**该群人类短消息的密度**学出来。

**上限(硬要求)**:

- `wild` **只允许**在"冷清 **且** 该群历史上接受过离谱话题"时使用;
- **"温和"仍是冷清期的硬门槛** —— **漂移再大也不能带刺**;
- `drift_level` / `anchor_policy` / `reaction_style` 都**可配置、可关闭**,并能按群覆盖。

**测试**:`wild` 在不满足条件时不会被选中;高漂移时温度门槛仍然生效(带刺内容照样被丢弃)。

## 📌 测试强度:不变量精确,启发式用区间与趋势

见 `docs/prompt-and-learning-design.md` **第十八节**。前面"把设计规则逐条变成断言"的要求要按此**分级**:

- **不变量**(去重、只采人类、不外溢、失败不写记录、沉默不计负面)**必须精确断言** —— 放宽它们等于没有验证;
- **启发式**(阶段分类、适配度、漂移档位、相关度)**用区间、方向与相对比较**,
  **只要给定输入、结果与预期没有过大差距即可**,**不要求精确值、也不必强行统一**。

每条断言都要能说清它属于哪一类、以及为什么这个强度合适。

## 📌 补充:跨群共享与来源可公开性闸门

选择与发送阶段要落实两条设计,见 `docs/prompt-and-learning-design.md` 第十五、13.8 节。

### A. 来源可公开性(13.8)—— 决定能否出群

素材在 P5b 采集时已打 `public` / `private` / `unknown` 档位。本阶段选择时必须遵守:

- 只有 `public` 素材能进入**跨群候选**;
- `private` 与 `unknown` **只允许在本群内使用**,绝不进入任何跨群候选;
- 默认档位是 `unknown`,即**默认不出群**;
- 判错代价不对称:公开图误判为私有只是少共享,私有图误判为公开**泄漏的是群友的脸** —— 所以**只有正面确认 `public` 才出群**。

**测试(不变量,精确断言)**:`private` / `unknown` 素材在"跨群候选"集合里**不得出现**;
被人工覆盖为 `public` 后才出现。

### B. 近似群跨群共享(15)—— 只在重合够高时共享

- 跨群候选还要再经 `share = clamp((overlap − floor) / (ceil − floor), 0, 1)` 闸门;
- `floor = 0.35`、`ceil = 0.75`,低于 floor **完全不共享**;
- 双向对称;相似度按**小时级**重算;
- 共享过去的是**素材引用 + 归纳后的群级条目**,**不得带来源消息 id 与昵称**。

**测试(启发式,单调性)**:重合更多的两组,`share` **不小于**重合更少的。
