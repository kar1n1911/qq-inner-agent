# P6d 三层决策 + 零模型初筛

你是 qq-inner-agent 的 Rust 移植工程师。工作区是隔离的 git worktree。

## 定位

`docs/prompt-and-learning-design.md` **第九节**。"要不要说话"是三件事,输入不同,必须拆开:

| 层 | 决策 | 主要输入 |
| --- | --- | --- |
| **① 回复必要性** | 这条消息要不要回 | 消息、是否被点名、`expectation`、冷却、配额、静默时段、activity 块 |
| **② 发起话题必要性** | 我要不要主动开话头 | **群的状态**、上次发言距今、想法池(`thoughts`)、节奏块、主动冷却、**该群作息** |
| **③ 说什么** | 怎么说才像这个人 | 人设 + personality + traits + 该群表达 + 长度分档 + 语气 |

## 现状与缺口

P6a 的 `engine` 已镜像 JS:有 `ingest`(debounce)、`tick`(due / minThinkInterval / busy / quiet / proactive 检查),
`trigger = pending ? "message" : pause`。所以**大部分初筛已经存在**,但:

1. **② 没有独立判定点** —— 现在"主动开话题"被折进 `pause` 触发里,没有自己的输入与概率;
2. **零模型初筛是隐式的** —— 散在 `ingest`/`tick` 里,没有一处明确的、可审计的"通过初筛才调模型"的分界。

## 任务

1. **把 ② 提出来**:独立于 `pending` 的"要不要主动开话头"判定,输入包括 `groupActivity`(已在 `media_select` 实现)与
   **该群作息**(从历史消息时段分布学,见 §11.6 第 3 条),有自己的概率与主动冷却;
2. **零模型初筛显式化**:在调用模型**之前**集中一处,列出并依次判定所有确定性闸门
   (静默时段、配额、冷却、无新消息、想法池为空、不在该群作息内),任一命中即不调模型;
3. **开关化默认关闭**:② 的新行为(独立判定 + groupActivity + 群作息)必须**开关化默认关闭**,
   默认路径与 JS 逐字一致(既有 `engine_parity` 照旧全过);③ 不在本阶段改动。

## 硬性约束

1. 不引入新依赖;不改 `rust/` 以外文件;
2. 复用 `media_select` 的 `group_activity` 与群作息,不要重复实现;
3. 中文注释,重点标注:①/② 的分界、初筛的每道闸门、以及"默认关闭→与 JS 一致"的开关边界。

## 验收

1. `cargo build --release`、`cargo clippy --all-targets -- -D warnings`、`cargo test` 全过;
2. 开关关闭时:`engine_parity` 的 golden 与 JS 逐条一致(**不回归**);
3. 开关开启时:
   - 初筛命中(静默/配额/冷却/无新消息/想法池空/不在作息)→ **不产生模型调用**(用 mock provider 断言零调用);
   - ② 的独立判定在"群冷清 + 有想法 + 在作息内"时以概率触发,反之不触发;
4. 测试强度按第十八节:不变量精确,启发式用区间/方向。
