# P6e 主人教学指令

你是 qq-inner-agent 的 Rust 移植工程师。工作区是隔离的 git worktree。

## 定位

新功能,**只做 Rust、开关化默认关闭**。见 `docs/working/prompt-and-learning-design.md` **第二十节**(唯一权威设计)。

## 需求

1. 在**私聊**里识别指令(`/记住 <内容>`、`/黑话 <词> = <意思>`、`/忘记 <关键词>`);
2. **只有 `ownerUin`**(配置,默认 `1950202917`)可用;群里任何人不能用;
3. **绕过常规学习门控**(8 条 / 300 秒),但**不绕过校验与自我审核**(§16):
   - `/记住` → 写 `long_term`(subject 取合法值);`/黑话` → 写 expressions/jargon;
   - `/忘记` → 按关键词删对应记忆/黑话;
   - `sources` 用**特殊标记**(如 `["owner-teaching"]`),**不得伪造人类消息来源**;
4. 指令命中后**不再进入普通回复流程**:成功 → 简短确认(如"记住了");失败 → 说明原因(如"没看懂");
5. 默认关闭(`enabled: false`),开启后才解析;关闭时这些消息**当作普通私聊**处理。

## 硬性约束

1. 不引入新依赖;不改 `rust/` 以外文件;
2. **开关化默认关闭**,默认路径与 JS 逐字一致;
3. 复用已合并的 `store`(learning/expressions 写入)、`memory`(self-review 若已实现则接上,否则用形式校验兜底);
4. 中文注释,重点标注:授权边界、绕过门控但不绕过校验、来源标记、指令与普通聊天的分流。

## 验收

1. `cargo build --release`、`cargo clippy --all-targets -- -D warnings`、`cargo test` 全过;
2. 测试:
   - 非 `ownerUin` 或群消息 → 指令**不生效**(当普通消息);
   - `/黑话 A = B` → 写入 expressions/jargon,`sources` 是 owner-teaching 标记;
   - `/记住 ...` → 写入 long_term;
   - `/忘记 ...` → 删除对应条目;
   - 非法指令(空内容、缺 `=`、超长)→ 失败且**不写入**,回复说明原因;
   - 默认关闭时 → 不解析,当普通私聊;
   - **不伪造人类来源**(测试断言 `sources` 不含真实消息 id)。
3. 测试强度按第十八节:不变量精确,启发式用区间/方向。

## 交付

1. `git add -A && git commit`,英文。
2. 一段话回报:实现了哪些指令、授权与来源怎么保证的、与设计的偏差或不确定点。
